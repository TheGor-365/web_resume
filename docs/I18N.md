# Web Resume internationalization (RU / EN / HY)

Rollback baseline: tag `web-resume-stable-2026-10-22` at `af44b4b`.
The feature branch is reviewed in increments and is NOT automatically merged.

## Data and code conventions
- Legacy `/`, `/services` and other paths remain valid in Russian.
  New explicit prefixes: `/ru`, `/en`, `/hy`.
- Request-scoped locale via `I18n.with_locale`; URL helpers pass non-default locale.
- Domain-specific YAML catalogs: `config/locales/<locale>/<domain>.yml`,
  with keys `site.<domain>.<key>`. Add translations in ALL languages.
- Existing Turbo Frame IDs (`toggler`, `experience`), Bootstrap, Chartkick
  and database remain untouched by the foundation.
- Avoid silent fallbacks masking missing translations. Proper nouns and
  technology names stay unchanged. Have Armenian copy reviewed by a native speaker.
- Do not replace Russian PostgreSQL `Experience` values. Database milestones
  and chart labels need stable translation identifiers in a later stage.
- Secrets (Gmail and Rails credentials) remain outside GitHub.

## Testing and review

```bash
git fetch origin
git merge --ff-only origin/feature/i18n-ru-en-hy
bin/rails zeitwerk:check
bin/rails test
git diff --check
```

Open `/en` and `/hy`, exercise all navigation tabs and confirm both Turbo
frames update in the chosen locale. Test modal certificates, videos,
WhatsApp/Messenger, and email validation (never send real test attachments
without intent). Disable browser automatic page translation for accurate checks.
The integration test `career_i18n_complete_content_test.rb` additionally
guards static EN/HY Turbo responses against remaining Russian UI copy.
Dynamic GitHub API descriptions are supplied by the external source.

When adding a portfolio event, add a durable identifier in
`PortfolioMilestoneHelper::REPOSITORY_EVENTS` (or handle an event with no
repository) and translations under `site.timeline.events` in all three
languages. Avoid writing translated strings into the database itself.
Armenian translations should be proofread by a native speaker.
